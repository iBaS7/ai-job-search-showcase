# Worked example (fictional posting and candidate data)

**Posting (fictional):** Senior Category Manager, Industrial IT, at a fictional manufacturer. Requirements: run RFx events, manage hardware and IT service categories, partner with engineering, use an e-sourcing tool.

| Requirement | Evidence in source documents | Used in letter? |
|---|---|---|
| RFx events | Four RFP rounds in an e-sourcing tool for a fleet tender, with a documented saving | Yes, with the documented figure |
| Hardware and IT categories | Purchasing of servers and network services in two roles (confirmed by me) | Yes, no figure (none documented) |
| Engineering partnership | Housing redesign with R&D, documented before/after temperatures | Yes |
| E-sourcing tool | Key user and trainer on the tool | Yes |
| Experience in the posting's own industry | None documented | Not mentioned in the letter; reported to me in chat |

**Result.** Four evidence-backed bullets, no invented numbers, no "I lack X" sentence. The mechanical checks (page counts, text extraction) run before I read the final PDF and submit it myself.
