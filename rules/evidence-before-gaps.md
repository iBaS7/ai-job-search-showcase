# Evidence before gaps

1. Search all source documents (CVs, long bios) for the skill or category in question.
2. Ask me if the documents are silent. I sometimes hold experience that was never written down.
3. Write only what the sources or I confirm. No figure without a source.
4. Keep remaining true gaps out of the cover letter unless the posting asks for them (for example a relocation situation); tell me instead.
5. Do not attribute work to a tool or method unless I confirmed it.
